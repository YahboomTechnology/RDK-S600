# Introduction
The D-Robotics RDK S600 is a high-performance edge AI development platform designed for embodied intelligence, robotics, and advanced AI applications. With up to 560 TOPS@INT8 AI computing performance, 18-core Arm Cortex-A78AE CPU, and high-bandwidth LPDDR5 memory, it provides the computing resources required for demanding edge AI projects. The RDK S600 supports up to 6 MIPI CSI-2 camera interfaces, PCIe Gen4 connectivity, multiple Gigabit and 10Gbps Ethernet interfaces, as well as a wide range of UART, SPI, I2C, and CAN/CAN-FD interfaces. This makes it suitable for multi-camera perception, sensor fusion, motion control, and other advanced robotics applications. The RDK S600 is also designed to support modern edge AI workloads, including VLA/VLM-based applications and multimodal AI inference. Developers can use the platform to move seamlessly from algorithm prototyping and AI model validation to real-world robotic system integration.
